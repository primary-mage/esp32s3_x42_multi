# esp32s3_x42_multi — 张大头 X42S_V2.0 一对多串口控制框架

ESP32-S3 一条 UART 挂多台张大头闭环步进电机。**x42s_v2.0 出厂固件是 Emm42_V5.0**（不是 ZDT_X 系列 V2.0），本框架按 EMM5.0 协议实现。

## ⚠️ 先确认固件版本

发 `01 1F 6B` 读版本：
- 回 `01 1F xx xx xx xx 6B` 且运动命令格式 = 速度(2B)+加速度档位(1B) → **Emm42_V5.0**，用本框架
- 若你后来刷过 ZDT_X 系列 V2.0 固件，协议不同（速度×10、角度×10、FB/FD 分开），需按 X 系列手册改驱动

## 硬件接线

| ESP32-S3 | 电机驱动板 | 说明 |
|---|---|---|
| GPIO4 (TX) | R/A/H | 电机 RX，多台并联 |
| GPIO5 (RX) | T/B/L | 电机 TX，多台并联 |
| GND | GND | 必须共地 |

- 串口参数：115200 8N1，电机菜单确认 `P_Serial=UART_FUN`、`Checksum=0x6B`（出厂默认）、`ID_Addr` 各台不同（1~255）
- 控制前每台必须先完成编码器校准（屏幕 `Not Cal` 时无法控制）
- ⚠️ TTL 一对多：官方建议一个 TTL 口挂 ≤4 台；多台 TX 并联直连有电平竞争风险，
  挂得多建议每台 TX 串二极管 + 公共上拉，或直接上 RS485 模块

## 代码结构

```
main/
├── zdt_x42.h / zdt_x42.c   # EMM5.0 协议驱动：总线初始化 + 命令封装 + 应答解析（互斥锁，多任务安全）

├── pair_home.h / .c        # 双机龙门回零状态机（押住两机→广播→先到等后到→解除堵转→退圈→设零点）

tools/
├── x42link.py              # 底层封装：X42Link 串口链路（空响应重试）+ Machine 机器模型
├── user_ui.py              # 面向操作员的三页 UI（①首页回零引导 ②操作 ③轨迹管理）
├── curve_editor.py         # 时间轴曲线编辑器（关键帧 + 直线插值，剪辑软件风格）
└── x42_ui.py               # 调试 UI（3 电机面板 + 回零参数）
```

## 用户 UI（面向操作人员）

```bash
python3 tools/user_ui.py
```

三页流程（操作员日常只用前两步）：
- **① 首页**：连接设备 → 引导复位（回零）→ 选择实验轨迹 → 进入操作
- **② 操作**：只读曲线预览 + 执行/暂停/停止，执行中高亮当前时间段
- **③ 轨迹管理**（调试用）：时间轴曲线编辑器 + 示教点动 + 保存/加载
- **搅拌段**（Y 轴支线任务）：在时间轴指定时间段插入 Y 轴振动（频率/振幅），
  执行到该窗口自动启动搅拌、X 照常运动，窗口结束等振动完成后继续；
  严格校验：搅拌期间 Y 曲线必须平坦（振动占用 Y），中心±振幅始终在行程内，搅拌段不重叠

### 轨迹 = 时间轴曲线

- 横轴 = 时间(s)，纵轴 = 距离(mm)，X/Y 两条轨道，相邻关键帧**直线插值**
- 段速度 = Δ距离/Δ时间，超过限速自动限速；编辑器里超速段标红
- 编辑：拖动改时间/位置、双击输入精确值、点击空白添加关键帧、Delete 删除（端点锁定）
- 总时长 / 速度上限可调；“用当前实际位置更新选中关键帧”做示教
- 轨迹存 `tools/trajectories/*.json`：
  `{"name", "speed_limit_mm_s", "duration_s",
    "tracks": {"X": [[t,pos]...], "Y": [[t,pos]...]},
    "stirs": [{"t0", "t1", "freq_hz", "amp_mm"}, ...]}`

### Y 轴坐标约定（仅 UI 层）

顶部 = 行程上限、底部 = 0、**向上为正**。机器/固件坐标不变，App 内统一镜像换算：
`Y_UI = 行程上限 − Y_机器`，回零后 Y 显示在行程上限处。

- 行程上限默认 X/Y 均为 180mm，改 `x42link.py` 的 `DEFAULT_TRAVEL_X/Y`
- 位置单位 mm，速度 mm/s；**连接后自动发送 GUARD 0**（关闭固件堵转自动恢复，由上位机检测堵转并报错，避免守护擅自运动/清零位置）

底层封装 `tools/x42link.py`：
- X42Link：串口链路（空响应自动重试）
- Machine：mm↔脉冲/raw 换算（raw 是编码器单位 65536/圈！）、绝对坐标直线插补
  （押住+GO 同时起步）、并行回零、软限位
- 关键坑：EMM5.0 绝对位置模式脉冲数是"相对零点的绝对目标"，方向字节=符号

## PC <-> ESP32 命令协议

一行一条，ESP 回复以 `CMD> ` 开头，每条命令以 `CMD> DONE` 结束（UI 过滤日志行）：

| PC -> ESP | 说明 |
|---|---|
| `VER` | 读所有电机版本 |
| `ENA <id> <0/1>` | 使能/去使能 |
| `POS <id> <CW/CCW> <pulses> <rpm> <accel> <REL/ABS>` | 位置模式定位 |
| `SPD <id> <CW/CCW> <rpm> <accel>` | 速度模式 |
| `STP <id/0>` | 停止（0=全部） |
| `ZERO <id>` | 当前位置清零（掉电不保存） |
| `OZERO <id>` | 存单圈零点（掉电保存） |
| `HOME <id> <mode>` | 触发回零 0~3 |
| `REL <id>` | 解除堵转保护 |
| `GUARD <0/1>` | 启用/禁用堵转自动恢复守护（用户 UI 连接后发 GUARD 0） |
| `VIB <id> <freq_dHz> <amp_0.1mm> <dur_s> <mirror>` | 振动搅拌：id=1 X轴 / id=2 Y轴双机，频率×10、半幅×10，dur=0 持续到 VIBSTP；定时驱动（到点切方向不等到位），偶数半周期后回中心停 |
| `VIBSTP` | 优雅停止振动（当前半周期到位后回中心） |
| `VSTATE` | 查振动状态：`CMD> VSTATE <state> <半周期数> <耗时ms>` |
| `STAT <id/0>` | 查询状态（0=全部） |

ESP -> PC：`CMD> OK ...` / `CMD> ERR ...` / `CMD> STAT <id> <en> <inpos> <stall> <clog> <pos_raw> <rpm>` / `CMD> DONE`

### 快速使用（EMM5.0 单位）

```c
zdt_x42_t m;
zdt_x42_bus_init(UART_NUM_1, 4, 5, 115200);   // 整个总线一次
zdt_x42_motor_init(&m, UART_NUM_1, 1);        // 每台电机一个句柄

zdt_x42_enable(&m, true, false);                              // 使能
zdt_x42_speed_mode(&m, true, 300, 10, false);                // CW 300RPM，加速度档位10
zdt_x42_pos_mode(&m, true, 300, 10, 6400, false, false);     // 相对转 6400 脉冲(2圈@16细分)
zdt_x42_stop(&m, false);                                     // 急停
```

### 多机同步（同时起步）

```c
// sync=true 先"押住"每台命令，再广播同步启动
zdt_x42_pos_mode(&m1, true,  200, 0, 3200, true, true);
zdt_x42_pos_mode(&m2, false, 200, 0, 3200, true, true);
zdt_x42_sync_start(&m1);   // 广播 00 FF 66 6B，多台同时动
```

### 单位约定（Emm42_V5.0）

| 参数 | 单位 | 例 |
|---|---|---|
| 速度 | RPM（整数） | 300 = 300 RPM |
| 加速度 | 1 字节档位 0~255，0=无曲线 | 10；每 +1RPM 用时 (256-acc)×50us |
| 位置命令 | 脉冲数，与细分相关 | 16 细分：3200 脉冲 = 1 圈 |
| 读位置(0x36) | 原始值，±(0~65535)=一圈 | `zdt_x42_raw_to_deg(x)` = x×360/65536 |

## EMM5.0 命令速查

| 功能 | 命令 |
|---|---|
| 使能/失能 | `01 F3 AB 01/00 00 6B` |
| 速度模式 | `01 F6 方向 速度(2B RPM) 档位(1B) 同步 6B` |
| 位置模式 | `01 FD 方向 速度(2B) 档位(1B) 脉冲(4B) 相对/绝对 同步 6B` |
| 立即停止 | `01 FE 98 00 6B` |
| 多机同步启动 | `01 FF 66 6B` / 广播 `00 FF 66 6B` |
| 触发编码器校准 | `01 06 45 6B` |
| 恢复出厂 | `01 0F 5F 6B` |
| 修改细分 | `01 84 8A 01 16细分 6B`（00=256细分） |
| 开/闭环切换 | `01 46 69 01 02 6B`（1=开环 2=闭环） |
| 读版本 | `01 1F 6B` |
| 读状态 | `01 3A 6B`（bit0使能 bit1到位 bit2堵转 bit3堵转保护） |
| 读位置 | `01 36 6B` |
| 读转速 | `01 35 6B`（RPM） |
| 读编码器 | `01 31 6B`（0~65535/圈） |
| 读电压/电流 | `01 24 6B`(mV) / `01 27 6B`(mA) |

## 错误码速查

| 返回 | 含义 |
|---|---|
| `ZDT_OK` | 命令成功（回 `02`） |
| `ZDT_ERR_COND` | 回 `E2`：条件不满足（没使能 / 堵转保护中） |
| `ZDT_ERR_REJECT` | 回 `01 00 EE 6B`：命令格式/校验模式不对 |
| `ZDT_ERR_TIMEOUT` | 没应答：查接线、波特率、`P_Serial`、ID 地址 |

## 注意事项

- 方向：`00=CW 01=CCW`；位置脉冲数正负由"方向字节"决定，不是带符号数
- 位置是**脉冲数**：改细分后每圈脉冲数变化（3200/圈 对应 16 细分），换算时注意
- 驱动菜单 `Response` 保持默认 `Receive`（立即回确认）；要到位信息用 `zdt_x42_read_status()` 轮询到位位
- 校验方式与电机菜单一致：默认 `ZDT_CHK_6B`；菜单改 XOR 时句柄里改 `m.checksum = ZDT_CHK_XOR`
- 广播命令（地址 0）不等待应答，只有地址 1 的电机回一条，下条事务自动清掉
